>
> - **`wc -m` はこの環境で文字数を返さない**（`LANG=` が空 = POSIX ロケールのため `wc -c` と同値）。文字数には `LC_ALL=C.UTF-8 wc -m` または Python `len()` を使う

> - 日本語 1 文字 = 3 バイト / ASCII 1 文字 = 1 バイトのため、**バイトと文字では同じ編集が逆向きに見えうる**
>
> 実測と履歴推移: `docs/artifacts/r1-mass-measurement-2026-07-27.md`。**本注記は単位の定義のみであり、質量を §A の計数対象に加えるものではない**（帳簿単一原則 / `fable-l3-protocol.md` §3）。
